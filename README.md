
# HealthFlow — Healthcare Operations Platform

A portfolio-grade healthcare operations platform built with Java,
Spring Boot microservices, React, PostgreSQL, Kafka and Redis.

## Project goals

- Secure authentication and role-based authorization
- Patient and doctor management
- Appointment booking with double-booking prevention
- Consultations, prescriptions and lab workflows
- Pharmacy inventory and billing
- Event-driven notifications and analytics
- Testing, observability and distributed tracing

## Technology stack

- Java 21
- Spring Boot and Spring Cloud
- Maven
- PostgreSQL and Flyway
- Apache Kafka
- Redis
- Spring Security and JWT
- React, Vite and TypeScript
- Docker Compose
- JUnit 5 and Mockito
- Prometheus, Grafana and Jaeger

## Development status

Phase 1: Repository and local infrastructure setup.

## Important

- The core project must run locally without paid services.
- Never commit `.env` or credentials.
- Use synthetic patient data only.
- This is a portfolio demonstration, not a clinical system.
